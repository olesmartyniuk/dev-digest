## Key design decisions (record, don't revisit)

1. **FindingCard reuse via injection, not import.**
   - `client/src/components/diff-viewer/**` is cross-route. Importing a route-private `_components/FindingCard` from it would point a shared component at a feature folder.
   - Instead, the viewer gets a `DiffFindingApi` whose `renderFinding(f)` returns an element. This is the same adapter shape as `DiffCommentApi`.
   - The route (`DiffTab/useDiffFindings.tsx`) supplies `<FindingCard …/>`.
   - Result: FindingCard is reused unchanged, there is no copy, and there is no boundary inversion.
2. **The grouped view lives with `DiffTab`.** It uses `prReview` strings and is specific to this feature. `components/diff-viewer` only adds a `FileCard` export to its barrel so the group can render cards.
3. **The order toggle is a URL param `?order=original`.** When the param is absent the order is `smart`, so the Smart view is the default and existing `?tab=diff` links stay valid.
4. **Findings are included regardless of accept/dismiss state.**
   - All findings from all reviews count and render, matching `usePrDetail`'s `findingsCount`.
   - `FindingCard` already renders the accepted/dismissed state muted. Excluding dismissed findings would make the card vanish on click.
5. **A finding whose `start_line` is not a rendered RIGHT-side line is never dropped.** It renders at the bottom of that file's body under "Findings not on a visible line", mirroring the `OutdatedComments` pattern.
6. **Classifier ordering stays exactly as specified.**
   - `e2e/README.md` → `tests`. Rule 2's `e2e/**` is evaluated before rule 4's `**/*.md`.
   - This is deliberate: an e2e README documents the flow harness, so it belongs with the flows it describes.
   - Record this in the test-row comment.
7. **`dist/**`, `build/**`, `e2e/**`, `docs/**`, `.github/**` and `.claude/**` are root-anchored** (first path segment), exactly as written in the spec. The patterns written `**/…` match at any depth. See Risks for `server/dist/…`.

**`helpers.ts`**, in this order:
- `export function normalizePath(path: string): string`
  - Replace `\` with `/` and strip a leading `./`.
  - Produce `segments = path.split('/')`, `basename = last segment`, `dirs = all but last`.
- `export function classifyPath(path: string): SmartDiffRole`. **First match wins, checked in exactly this order.** Add a doc comment saying so.
  1. **boilerplate** if any of these holds:
     - `basename.endsWith('.lock')`
     - `LOCKFILE_BASENAMES.has(basename)`
     - `ROOT_BOILERPLATE_DIRS.has(segments[0])` and `segments.length > 1`
     - `dirs.includes('__snapshots__')`
     - `basename.endsWith('.snap')`
     - `basename.includes('.generated.')`
     - `basename.endsWith('.min.js')`
  2. **tests** if any of these holds:
     - `TEST_FILE_RE` or `SPEC_FILE_RE` matches the basename
     - `dirs` contains any `TEST_DIR_SEGMENTS` entry
     - `ROOT_TEST_DIRS.has(segments[0])` and `segments.length > 1`
  3. **wiring** if any of these holds:
     - `BARREL_BASENAMES.has(basename)`
     - `basename.includes('.config.')`
     - `TSCONFIG_RE`
     - `basename.startsWith('.eslintrc')`
     - `basename.startsWith('.env')`
     - `DOCKER_COMPOSE_RE`
     - `ROOT_WIRING_DIRS.has(segments[0])` and `segments.length > 1`
  4. **docs** if any of these holds:
     - `MARKDOWN_RE`
     - `ROOT_DOCS_DIRS.has(segments[0])` and `segments.length > 1`
     - `basename.startsWith('README')` or `basename.startsWith('CHANGELOG')`
     - `basename === 'LICENSE'`
  5. otherwise **core**.
- `export function buildSmartDiff(files: SmartDiffInputFile[]): SmartDiff`
  - Classify each file.
  - Bucket by role. Sort each bucket by `path` ascending with `localeCompare`, because the DB order is undefined.
  - Emit `groups` in `ROLE_ORDER`, **omitting empty roles**.
  - Each file is `{ path, additions, deletions, pseudocode_summary: null, finding_lines: [] }`.
  - `split_suggestion = { too_big: false, total_lines: Σ(additions+deletions), proposed_splits: [] }`.
